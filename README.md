# 2laba_2sem — Три задачи на Swift

Лабораторная №2, 2 семестр. Три мини-задачи, каждая продублирована на 11 языках (эталон — Swift).

## Что внутри
- `Chessboard/` — шахматная доска (`Chessboard.swift` + .py/.js/.go/.java/.kt/.rs/.cs/.hs/.rb)
- `TimeValidator/` — проверка времени
- `WaterBottles/` — задача про бутылки

## Стек
Swift (основной), сравнение с другими языками

## Запуск
```bash
swift Chessboard/Chessboard.swift
swift TimeValidator/*.swift
swift WaterBottles/*.swift
```

## Что изучено
Базовый Swift, ветвления и циклы, сравнение синтаксиса языков.
