# Три задачи на разных языках программирования

![Стек](https://img.shields.io/badge/Swift%20%C2%B7%20C%2B%2B%20%C2%B7%20Python-334155?style=flat-square) ![Семестр](https://img.shields.io/badge/семестр-2-0f766e?style=flat-square) ![Статус](https://img.shields.io/badge/статус-%D0%A3%D1%87%D0%B5%D0%B1%D0%BD%D1%8B%D0%B9%20%D0%BF%D1%80%D0%BE%D0%B5%D0%BA%D1%82-64748b?style=flat-square)

Лабораторная №2: шахматная доска, проверка времени и задача об обмене бутылок. Реализации на Swift можно сравнить с версиями на других языках.

## Содержание

| Каталог | Задание |
|---|---|
| [Chessboard](Chessboard/) | Шахматная доска |
| [TimeValidator](TimeValidator/) | Проверка формата времени |
| [WaterBottles](WaterBottles/) | Обмен пустых бутылок |

В каталогах есть реализации на C++, Python, JavaScript, Go, Java, Kotlin, Rust, C#, Ruby и Swift. В отдельных заданиях также используются Haskell и ассемблер.

## Запуск на Swift

```bash
swift Chessboard/Chessboard.swift
swift TimeValidator/TimeValidator.swift
swift WaterBottles/WaterBottles.swift
```

## Другие реализации

Запускайте один файл выбранного языка. Например:

```bash
python3 TimeValidator/TimeValidator.py
c++ -std=c++17 WaterBottles/WaterBottles.cpp -o bottles
./bottles
```

Версии служат для сравнения решений и синтаксиса; поведение каждой реализации нужно проверять отдельно.
